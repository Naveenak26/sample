# Talent Compass – How to Execute

This project is a single-page website (`java.html`) with no build step.

## Prerequisites
- Python 3 installed (for running a local static server)
- Any modern browser (Chrome, Edge, Firefox)

## Run locally
1. Open a terminal in the project folder:
   ```bash
   cd /workspace/sample
   ```
2. Start a local server:
   ```bash
   python3 -m http.server 4173 --bind 0.0.0.0
   ```
3. Open the app in your browser:
   - `http://127.0.0.1:4173/java.html`

## Stop the server
- Press `Ctrl + C` in the terminal where the server is running.

## Quick direct-open option (without server)
You can also open the file directly in a browser:
- `/workspace/sample/java.html`

> Note: Running with a local server is recommended for the most reliable behavior.
